## Selected projects

### [InterviewAI](https://github.com/SamyaLaddha/interview-ai)

**AI-powered interview coaching platform**

<a href="https://prepwithinterviewai.vercel.app"><img src="https://img.shields.io/badge/Live%20Demo-6B5B4D?style=flat-square" alt="Live Demo"/></a>
<img src="https://img.shields.io/badge/Full--Stack%20Application-E8DDCC?style=flat-square&labelColor=E8DDCC&color=E8DDCC" alt="Full-stack application"/>

Built and deployed a web application that helps users practise interviews and receive feedback on their spoken answers.

- Transcribes recorded answers using Faster-Whisper.
- Analyses relevance, sentiment, speaking speed, filler words, and pauses.
- Combines five metrics into a confidence score and provides a results dashboard.
- Includes authentication, attempt history, comparison tools, and guest access.

**Tech:** Python, FastAPI, React, Vite, PostgreSQL, SQLAlchemy, Faster-Whisper

### [DefectLens AI](https://github.com/SamyaLaddha/DefectLens-AI)

**Industrial visual anomaly detection**

An ongoing project applying the Student-Teacher Feature Pyramid Matching (STFPM) approach to identify anomalies in industrial product images.

- Implements a teacher-student deep learning architecture using pretrained ResNet features.
- Trains separate models for Bottle, Cable, and Screw from the MVTec AD dataset.
- Includes configurable training, validation, checkpoints, and a model evaluation workflow.

**Tech:** Python, PyTorch, torchvision, ResNet, FastAPI, React, Vite

### [AI Excuse Generator](https://github.com/SamyaLaddha/ai-excuse-generator)

**Multilingual text and voice generation**

An LLM-powered application that generates contextual responses with controls for scenario, tone, and urgency.

- Uses Zephyr-7B for text generation.
- Supports English to Hindi translation and text-to-speech output.
- Includes ranked suggestions, history, favourites, and ready-to-send message drafts.

**Tech:** Python, Hugging Face Transformers, PyTorch, MarianMT, gTTS, Pandas

### Other work

Alongside these projects, I've worked on regression, classification, clustering, CNN-based image classification, and exploratory data analysis of 150K+ Uber booking records during AI/ML training.
